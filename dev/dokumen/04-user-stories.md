## 4. User Stories

| ID | User story | Kriteria penerimaan |
|---|---|---|
| US01 | Sebagai ibu, saya ingin menulis resep sedikit demi sedikit per layar, agar saya tidak bingung melihat formulir yang panjang | Setiap layar hanya berisi satu bagian resep dan satu tombol utama |
| US02 | Sebagai ibu, saya ingin resep yang sedang saya tulis tersimpan sendiri, agar tulisan saya tidak hilang kalau HP mati atau saya keluar aplikasi | Setelah menekan "Lanjut", resep muncul di daftar "Belum selesai" dan bisa dilanjutkan |
| US03 | Sebagai ibu, saya ingin memotret halaman buku tulis saya dan melampirkannya ke resep, agar tulisan asli tetap tersimpan walau belum sempat diketik | Foto tersimpan, tampil di halaman resep, dan bisa dipilih untuk masuk buku |
| US04 | Sebagai ibu, saya ingin menulis bahan satu per baris seperti di buku tulis, agar tidak perlu memisahkan angka dan satuan | Kolom bahan menerima teks bebas, setiap baris tampil sebagai satu bahan |
| US05 | Sebagai budhe, saya ingin mencari resep dengan mengetik nama masakan atau bahannya, agar cepat menemukan resep yang mau saya masak | Hasil pencarian muncul saat mengetik, mencakup judul dan bahan |
| US06 | Sebagai budhe, saya ingin layar HP tidak mati saat membaca resep, agar saya tidak perlu menyentuh HP dengan tangan kotor | Di mode baca layar tetap menyala selama halaman terbuka |
| US07 | Sebagai budhe, saya ingin melengkapi resep uti yang saya ingat berbeda, agar resep keluarga makin lengkap | Budhe bisa mengedit resep atau membuat resep baru dengan judul berbeda |
| US08 | Sebagai anggota keluarga, saya ingin bisa mengembalikan resep ke versi sebelumnya, agar resep tidak rusak kalau ada yang salah edit | Daftar riwayat menampilkan tanggal dan nama pengedit, tombol "Kembalikan versi ini" tersedia |
| US09 | Sebagai anggota keluarga, saya ingin menandai resep yang takarannya belum pasti, agar anggota lain tahu resep itu perlu dicek | Resep berstatus "Perlu dicek" tampil dengan penanda yang jelas |
| US10 | Sebagai ibu, saya ingin menuliskan cerita dan kenangan tentang uti di setiap resep, agar cucu tahu asal usul masakan itu | Kolom cerita dan kenangan tersedia dan tampil di halaman resep buku |
| US11 | Sebagai admin, saya ingin membuat akun untuk ibu dan budhe, agar mereka tidak perlu mendaftar sendiri | Admin bisa membuat akun dengan nama, email, dan password awal |
| US12 | Sebagai admin, saya ingin mengatur ulang password anggota, agar anggota yang lupa password bisa masuk lagi tanpa alur email yang membingungkan | Admin bisa menetapkan password baru dari dashboard |
| US13 | Sebagai ibu, saya ingin membuat buku khusus berisi resep uti, agar bisa dicetak sebagai kenang kenangan | Pilihan "Pemilik resep: Uti" menghasilkan PDF berisi resep uti saja |
| US14 | Sebagai admin, saya ingin buku PDF berukuran A5 dengan daftar isi dan nomor halaman, agar bisa langsung dibawa ke percetakan | PDF berukuran A5, memiliki sampul, persembahan, kata pengantar, daftar isi, dan nomor halaman |
| US15 | Sebagai admin, saya ingin data dan foto tercadang otomatis ke Google Drive, agar resep keluarga tidak hilang kalau layanan bermasalah | Backup berjalan harian, status terakhir terlihat di dashboard |
